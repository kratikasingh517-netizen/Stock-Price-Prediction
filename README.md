# Stock Price Prediction using Machine Learning

## Project Overview
This project predicts stock prices using Machine Learning techniques and historical stock market data.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- yfinance

## Features
- Historical stock data analysis
- Feature engineering
- Random Forest Regression model
- Stock price prediction
- Data visualization

## Dataset
Dataset collected using Yahoo Finance API.

## Output
The model predicts future stock closing prices based on historical trends.
